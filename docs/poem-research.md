# マンションポエム リサーチ・メモ

「既存マンションポエムDB」と生成ロジックを構築するために参照した情報源と、
そこから抽出した語彙・パターンの蒸留メモ。**実在ポエムの逐語転載は行わず、
語彙・言い回し・構文パターンのみを一般化して利用**している。

## 抽出したパターン（生成に反映）

1. **とにかく立地押し**：頻出語1位「街」、2位「都心」。部屋・設備にはほぼ触れない。
   → 語彙プールを「立地・情景」中心に構成（`AXIS_POOLS[*].scenes`）。
2. **当て字・言い換え**：住む→棲む/澄む/住まう、時→刻、森→杜、楽しむ→愉しむ、
   家→邸（いえ）。
   → 述語動詞に「纏う・刻む・継ぐ・住まう・澄む」等を採用（`VERBS`）。
3. **句読点作法**：読点で細かく区切り、末尾に「。」を置く。
   → テンプレートを「〜、〜、〜。」構造に。
4. **格式語**：静謐・叡智・品格・頂・掌中に収める・私領域。
   → 邸宅軸の `values`/`CLOSINGS` に採用。
5. **共起クラスタ → 7属性軸**：共起ネットワークの語群を
   都心・利便／自然・環境／邸宅・格式／文化・歴史／暮らし・街／景観・美／開放・空間
   に再構成（`src/lib/attributes.ts`）。各駅をこの軸で重み付けし、
   エリア↔ポエムの相関ロジックの入力にしている。

## エリア相関の考え方

各駅の属性ベクトル（`src/data/stations.ts`）は、その街の一般的なイメージを戯画化して
重み付けしたもの（例：港区＝邸宅・都心、世田谷＝暮らし・自然、江東湾岸＝開放、
台東＝文化・下町）。生成時は属性重みで語彙軸を選び、テンプレートに充填する。

## 法務・倫理メモ

- 出力（物件名・コピー・画像）はすべて**架空（パロディ）**。実在ブランド名は使わず
  架空の接頭辞・接尾辞を組み合わせる（`BRAND_PREFIXES` / `BRAND_SUFFIXES`）。
- 画像は実広告のスクレイピングではなくAI生成（`scripts/generate-images.ts`）。
  未生成時は属性テーマのSVG背景にフォールバック。
- 画面フッターに免責を明記。
